¿Qué es Linux?

⚙️Linux El kernel: el programa que controla las piezas de la computadora (memoria, disco, procesador)
+
🧰GNU Las herramientas: comandos como ls y cd, y la shell bash
=
💻GNU/Linux El sistema operativo completo. En el día a día todos le dicen “Linux”

Servidores y web

3 · atajos

Atajos para escribir menos (y equivocarte menos)

TabAutocompleta nombres de carpetas y archivos. Dos veces Tab muestra las opciones. 
$ cd doc[Tab]
$ cd documentos/
↑ ↓Repite comandos que ya escribiste, sin volver a teclearlos. 
$ [↑]
$ ls -la
clear  o  Ctrl + LLimpia la pantalla. No borra nada, solo despeja la vista.
Ctrl + CCancela lo que se está ejecutando. Úsalo si la terminal se queda “trabada”. (Aquí no copia texto)
catMuestra lo que tiene un archivoconcatenate
cat archivoImprime el contenido en la terminal. 
$ cat bienvenida.txt
¡Bienvenida/o a la carpeta del curso de Linux de Curies Community!
Aquí vas a practicar pwd, ls, cd, cat, cp, mv y rm.
Pista: hay un archivo oculto. ¿Lo encuentras?
cat ruta/archivoLee un archivo de otra carpeta. 
$ cat documentos/notas.txt
Linux = el kernel
GNU = las herramientas
cat carpeta ✗cat solo lee archivos. 
$ cat documentos
cat: documentos: Is a directory
cpCopia: el original se quedacopy · cp origen destino
cp archivo nuevoEl nombre no existe: se crea la copia con ese nombre. 
$ cd documentos
$ cp notas.txt copia.txt
$ ls
copia.txt  notas.txt  tareas.txt
cp archivo carpeta/El destino es una carpeta: la copia entra ahí con el mismo nombre. 
$ cp tareas.txt ../fotos/
$ ls ../fotos
playa.jpg  tareas.txt
cp -r carpeta nuevaCopia una carpeta completa con todo lo de adentro. 
$ cd ..
$ cp -r fotos fotos2

Si el destino ya existe, cp lo reemplaza sin avisar. Usa cp -i para que pregunte.

mvMueve o cambia el nombremove · mv origen destino
mv archivo carpeta/Mueve el archivo a otra carpeta. Ya no está en el origen. 
$ mv fotos/playa.jpg documentos/
$ ls fotos
tareas.txt
$ ls documentos
copia.txt  notas.txt  playa.jpg  tareas.txt
mv viejo nuevoEn la misma carpeta, con otro nombre: renombra. 
$ cd documentos
$ mv tareas.txt pendientes.txt
$ ls
copia.txt  notas.txt  pendientes.txt  playa.jpg

A diferencia de cp, para mover carpetas no necesita -r.

Si ya existe un archivo con el nombre del destino, mv lo reemplaza sin avisar. mv -i te pregunta antes.

rmBorra para siempreremove
rm archivoBorra un archivo. 
$ cd papelera
$ rm borrame.txt
rm -i archivoPregunta antes de borrar. 
$ rm -i viejo/nota-vieja.txt
rm: remove regular file ...? n
rm -r carpetaBorra una carpeta y todo lo de adentro. 
$ rm -r viejo
$ ls
$

rm no usa papelera de reciclaje: lo borrado no se recupera. Nunca ejecutes sudo rm -rf copiado de internet sin entenderlo.

tu turno

Ejercicio: explora y ordena curies-linux

  1. Empieza limpio: cd ~, rm -rf curies-linux, repite el git clone y entra con cd curies-linux
  2. Encuentra el archivo oculto y léelo: ls -a y cat
  3. Entra a documentos y copia notas.txt como respaldo.txt
  4. Mueve respaldo.txt a fotos con una ruta relativa (../)
  5. Ve a papelera, borra borrame.txt y la carpeta viejo
  6. Comprueba con ls -la que todo quedó como querías

¿Algo salió mal? Repite el paso 1 y empieza de nuevo. -f = force: borra sin preguntar.
